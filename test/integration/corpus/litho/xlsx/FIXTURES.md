# litho/xlsx corpus fixtures

Self-authored SpreadsheetML workbooks that cover what Microsoft Excel prints. Each fixture is an unpacked OOXML part tree under `parts/<name>/`, hand-written ECMA-376 Transitional XML as Excel 2016+ writes it: real content and relationship types, `mc:Ignorable` extensions, and a cached value for every formula, since printing shows cached values. `go run ./test/integration/cmd/corpus build --corpus=litho/xlsx` zips each tree deterministically into the testdata. An `options.json` beside the parts holds the Gotenberg route options the fixture converts with.

The references are Microsoft's: Office for the web prints each document through Microsoft Graph (`make corpus-references CORPUS=litho/xlsx` with `LITHO_CORPUS_MSGRAPH_TOKEN`, see `cmd/corpus/msgraph.go`), and each reference records the day it was built, since the service has no version to pin. Graph applies no conversion options, so the fixtures with an `options.json` (7: `options_landscape_pages`, `options_single_page`, `options_paper_landscape`, `options_paper_fit`, `options_sheets_by_name`, `options_sheet_numbers`, `options_hidden_sheets`) have no reference of their own: the five whose `options.json` names `reference_of` borrow the reference of the fixture it names, a workbook whose own page setup is what the options ask, and the `diff` feature leaves the other two unscored; the `robustness` feature and the other cells still read them. Every other fixture converts: Office refusing one means the part tree is not valid OOXML, and the tree is fixed, not the reference skipped. Hostile documents are generated in Go from `minimal` and are listed in their own section.

Fonts are Calibri, Cambria, Arial, Times New Roman and Courier New, which have metric-compatible free substitutes, plus DejaVu Sans, Noto Sans CJK, Noto Sans Thai and Noto Sans Devanagari for other scripts. `&D`, `&T` and `&F` header codes print the conversion date and file name, so those areas differ between runs.

## Paper documents

`corpus build` generates, beside the hostile documents, the paper documents from two committed bases (`paperDocs` in `cmd/corpus/papers.go`), never committed: the same bases give the same bytes. Each sheet states its paper by its `pageSetup` `paperSize` code (ECMA-376 Part 1, 18.3.1.63: 8 A3, 9 A4, 11 A5, 13 B5, 1 Letter, 5 Legal, 3 Tabloid, 7 Executive) and its `orientation`. Code 13 is the JIS B5 Excel prints, 182 by 257 mm: the table names ISO B5 as an envelope alone, code 34, which Excel prints on Letter.

| Fixture                                                                             | Count | Page setup                                                                                                                                                  |
| ----------------------------------------------------------------------------------- | ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `paper-grid`                                                                        | 1     | Committed: a grid of 20 columns by 130 rows, wider and longer than any paper, with a header and a "Page X of Y" footer, on portrait Letter (`paperSize` 1)  |
| `paper-fit`                                                                         | 1     | Committed: 16 columns by 120 rows fitted to one page wide (`fitToPage`, `fitToWidth` 1, `fitToHeight` 0), so the paper decides the scale and the pages down |
| `paper-grid-<paper>-<orientation>`                                                  | 16    | `paper-grid` on A3, A4 and A5 (ISO 216), B5 (JIS), Letter, Legal, Tabloid and Executive, in both orientations                                               |
| `paper-fit-<paper>-<orientation>`                                                   | 6     | `paper-fit` on A5, Letter and A3, in both orientations                                                                                                      |
| `paper-grid-option-<paper>-<orientation>`, `paper-fit-option-<paper>-<orientation>` | 12    | The base unchanged, `options.json` naming A5, Letter or A3 and `landscape` for the landscape ones, `reference_of` the generated workbook of that paper      |

## Accepted disagreements

- `paper_sizes`: Excel's export prints a paper it lacks on Letter, turned as the sheet asks: the envelopes #10 and DL (codes 20 and 27), the Japanese postcard (43) and A6 (70). litho prints the paper the code names (ECMA-376 Part 1, 18.3.1.63). The seven other sheets agree, JIS B5 at code 13 among them.

## Hostile documents

`corpus build` generates these from `minimal` (`hostile_*.go` in `cmd/corpus`); they are never committed. The `robustness` feature converts them, and every fixture above, in a child process and checks each ends as [`robustness.json`](robustness.json) says: a PDF, the error the document must be refused with, or `any` end but a crash or a panic, always under the memory bound (1 GiB unless the document sets its own), with no network request, no text a document pulls from the machine (`forbid`) and the text it must keep (`require`). No reference is built for them.
