# litho/docx corpus fixtures

Self-authored Word documents that cover as much of WordprocessingML as a converter meets. Each fixture is an unpacked ECMA-376 Transitional part tree under `parts/<name>/`, written as Word 2016 and later writes it: the Word namespaces with `mc:Ignorable`, real content types and relationship types. `go run ./test/integration/cmd/corpus build --corpus=litho/docx` zips each tree deterministically into `testdata/litho/docx/sources/<name>/<name>.docx`, with its `options.json` beside it when the tree has one.

The references are Microsoft's: Office for the web prints each document through Microsoft Graph (`make corpus-references CORPUS=litho/docx` with `LITHO_CORPUS_MSGRAPH_TOKEN`, see `cmd/corpus/msgraph.go`), and each reference records the day it was built, since the service has no version to pin. Graph applies no conversion options, so the fixtures with an `options.json` (5: `option-paper-size`, `para-outline-levels`, `protected`, `option-paper-over-landscape`, `option-landscape`) have no reference of their own: the two whose `options.json` names `reference_of` borrow the reference of the fixture it names, a document whose own page setup is what the options ask, and the `diff` feature leaves the other three unscored; the `robustness` feature and the other cells still read them. Every other fixture converts: Office refusing one means the part tree is not valid OOXML, and the tree is fixed, not the reference skipped.

Fonts are Calibri, Cambria, Arial, Times New Roman, Courier New, DejaVu Sans, Noto Sans CJK, Noto Sans Thai and Noto Sans Devanagari, which have metric-compatible or identical free faces. `run-fonts-fallback` names missing fonts on purpose. Media are small generated PNG, JPEG, GIF, BMP, TIFF, SVG, EMF and WMF files.

`minimal` is the smallest valid document: one paragraph, "Hello". The hostile documents derive from it; they are generated in Go and listed in the hostile section.

## Hostile documents

`corpus build` generates these from `minimal` (`hostile_*.go` in `cmd/corpus`); they are never committed. The `robustness` feature converts them, and every fixture above, in a child process and checks each ends as [`robustness.json`](robustness.json) says: a PDF, the error the document must be refused with, or `any` end but a crash or a panic, always under the memory bound (1 GiB unless the document sets its own), with no network request, no text a document pulls from the machine (`forbid`) and the text it must keep (`require`). ## Not authored

| Feature                                                      | Why                                                                                                                                                                                  |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `w:basedOn` cycle, encrypted and signed packages, VBA        | A style cycle makes LibreOffice refuse the file, so it belongs with the hostile documents. Encryption needs a CFB container, signatures XML-DSig, VBA a `.docm`: none is a part tree |
