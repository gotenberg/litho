# litho/html corpus fixtures

HTML and Markdown sources litho authored, converted twice: by Chromium, through the Chromium route of the Gotenberg image `GOTENBERG_IMAGE` in `corpus/versions.env` pins, and by litho. The `diff` feature scores litho's conversion against Chromium's (see `FEATURES.md`). Each source is a self-contained directory, `sources/<name>/`, holding `index.html` (or, for a Markdown source, `index.md` and no `index.html`), the files it names, and optionally `options.json`, the route options it is converted with. Nine sources carry over the Chromium route's option cases from Gotenberg's own test documents (see "Gotenberg's option cases"); this file documents the options, the references and litho's PDFs of both.

| Path                | What it holds                                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `sources/`          | The 102 sources                                                                                                                 |
| `corpus references` | Posts each source to the Gotenberg image and writes `testdata/litho/html/references/<name>.pdf` and their `manifest.json`       |
| `../../../fixture/` | Reads a source directory and its `options.json` for `corpus references` and the `diff` feature (shared with the Office corpora) |

## Per-fixture options

A source converts at the corpus defaults unless its directory holds `options.json`, a JSON object whose keys are form fields of Gotenberg's Chromium route (`FormDataChromiumPdfOptions` and `FormDataChromiumOptions` in Gotenberg's `pkg/modules/chromium/routes.go`), spelt as the route spells them. Two readers apply it alike: `corpus references` posts each key as the form field of the same name, and the `diff` feature maps it to `pdf.With*` options through `fixture.Load`. A key outside the table, or one spelt in another case, fails both.

| Key                      | Type    | Default                 | Chromium side                                                                        | litho side                                                                                                                   |
| ------------------------ | ------- | ----------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `paperWidth`             | inches  | A4, `210mm`             | `paperWidth`                                                                         | `WithPaper`, or `WithDefaultPaper` when the CSS page size is preferred, 72 points per inch; A4 left out is 595.92            |
| `paperHeight`            | inches  | A4, `297mm`             | `paperHeight`                                                                        | `WithPaper`, or `WithDefaultPaper` when the CSS page size is preferred, 72 points per inch; A4 left out is 841.92            |
| `marginTop` and siblings | inches  | unset, the route's 0.39 | `marginTop`, `marginRight`, `marginBottom`, `marginLeft`                             | `WithMargins`, truncated to whole points, then rounded to whole CSS pixels, as Chromium lays them out; unset is 27.75 points |
| `landscape`              | boolean | `false`                 | `landscape`                                                                          | `WithOrientation(OrientationLandscape)`                                                                                      |
| `scale`                  | number  | unset (1)               | `scale`                                                                              | `WithScale`                                                                                                                  |
| `singlePage`             | boolean | `false`                 | `singlePage`                                                                         | `WithSinglePage`, which sets `nativePages` aside                                                                             |
| `nativePages`            | string  | unset (every page)      | `nativePages`                                                                        | `WithPageRanges`                                                                                                             |
| `preferCssPageSize`      | boolean | `true`                  | `preferCssPageSize`                                                                  | `WithDefaultPaper` in place of `WithPaper`                                                                                   |
| `printBackground`        | boolean | `true`                  | `printBackground`                                                                    | `WithCanvasBackground`                                                                                                       |
| `nativeBookmarks`        | boolean | `false`                 | `nativeBookmarks`                                                                    | `WithOutline`                                                                                                                |
| `emulatedMediaType`      | string  | `print`                 | `emulatedMediaType`                                                                  | `WithMediaType`                                                                                                              |
| `emulatedMediaFeatures`  | object  | unset (none)            | `emulatedMediaFeatures`, as compact JSON                                             | `WithMediaFeatures`                                                                                                          |
| `header`                 | file    | unset                   | the named file posted as `header.html`                                               | none: litho draws no template, and a source that names one names the `bands` that stand for it (see below)                   |
| `footer`                 | file    | unset                   | the named file posted as `footer.html`                                               | none, as for `header`                                                                                                        |
| `installedFonts`         | list    | unset (none)            | no field: the container is started with the named fixture font directories installed | `WithConvertFontDirs`, each directory after the Gotenberg image's fonts                                                      |
| `expectedText`           | file    | unset (none)            | no field, and the file is not posted                                                 | none: the `diff` feature scores the text against the named file, not Chromium's (see "Expected text")                        |

The defaults are the options every source was converted with before the file existed, so a source without it scores as before; they differ from the route's own defaults (Letter paper, no backgrounds, the paper size preferred over `@page size`). A header or footer names a file of the source directory (a plain file name, at most 64 KiB); `corpus references` posts every other file of the directory, `options.json` excepted. Chromium lays an inch value out on a grid of its own: 8.5 by 11 inches gives 612 by 792 points, but 8.27 inches gives 595.92, not 595.44; a source that sets the paper should pick a size Chromium keeps exact, or the `pages` score reads the rounding as a size mismatch.

Gotenberg's `printBackground=false` is not Chromium's: the route always injects `html { -webkit-print-color-adjust: exact !important }`, and without `printBackground` adds `html, body { background: none !important }`. Element backgrounds therefore print either way, and the option only drops the root and body backgrounds (`no-background` shows it).

A symbolic link in a source directory is followed by both sides (`curl -F` and `os.DirFS`); `font-face` links Ahem from `pkg/internal/layout/testdata/Ahem.ttf` rather than committing a second copy, `variable-font` links `pkg/internal/typography/varfont/testdata/varfont.ttf` likewise, and the sources that reuse another source link its files.

litho draws no Chromium template: `header-footer`, `header-default-classes` and `single-page-header` keep their `header` and `footer` files, which `corpus references` posts to Chromium, and name under `bands` the bands that stand for them (`pdf.WithHeader`, `pdf.WithFooter`). Each band holds its template in a `#header` or `#footer` element and `band.css`, which imports `chromium-template.css`: the stylesheet of Chromium's template page and its text defaults, the box spanning the page across the side margins, `title`, `pageNumber` and `totalPages` as `string(document-title)`, `counter(page)` and `counter(pages)`. `band.css` sets the box's height to the margin and, for the two sources whose templates set `body { margin: auto 20px }`, insets it by 20 pixels. Measured on 2026-11-13 against the references built from the templates: every source passes `diff` with every word where Chromium's template puts it to 0.8 points, at a layout score of 0.952, 0.946 and 0.945.

`markdown-plain` has no `index.html`: `corpus references` posts `index.md` to `/forms/chromium/convert/markdown` with an `index.html` it writes, `<!doctype html><html><head><meta charset="utf-8"><title></title></head><body>{{ toHTML "index.md" }}</body></html>`, the document litho's Markdown converter writes around the rendered Markdown, and litho converts `index.md` as `pdf.Format("markdown")`.

`markdown-template` sets `markdownTemplate`, litho's own option (`pdf.WithMarkdownTemplate`), which the Markdown route cannot take: Gotenberg's route posts the template as `index.html` and sanitises what it renders. Its reference is therefore borrowed: `markdown-template-html` is the HTML document litho's Markdown converter renders `index.md` into, byte for byte, and Chromium prints that document as an HTML source. Rebuild it whenever `index.md`, `template.html` or the Markdown renderer changes. Measured on 2026-11-11 with the pinned image: Chromium prints the twin on one page of 420 by 594 points titled "Notebook: Field Notes on Paper", as litho prints `markdown-template`.

## The Chromium references

```bash
make corpus-references CORPUS=litho/html
```

runs `corpus references`, which starts the pinned image on a free loopback port and posts each source directory, `index.html` and every sibling file, to `/forms/chromium/convert/html` with the fields of its options (by default `paperWidth=210mm`, `paperHeight=297mm`, `emulatedMediaType=print`, `printBackground=true` and `preferCssPageSize=true`, the route's margins left at their default, 0.39 inch), and writes each PDF to `test/integration/testdata/litho/html/references/` with a `manifest.json` recording the image and the SHA-256 of the source's files, its options and the PDF. `FIXTURES=a,b` rebuilds only the sources named. Backgrounds are printed because a document converter paints them; the route's default leaves them out. `make corpus-prepare CORPUS=litho/html` rebuilds the references of the sources that changed and derives their goldens again, and the `diff` cell refuses a reference built from another source, options or image. Chromium's A4 page is 595.92 by 841.92 points, a rounding of 8.27 by 11.7 inches, and its text column starts 27.75 points in, 37 CSS pixels; litho converts on that measured geometry rather than the exact A4 so the two wrap and break pages alike.

The text F1 score reads Chromium's PDF with PDF.js, except for a source that names an expected text (see "Expected text").

## litho's conversion

The `diff` feature converts each source at its options (by default on Chromium's measured A4 page, 595.92 by 841.92 points with 27.75 point margins, for print), the source's directory as the resource root and the Liberation, DejaVu, Noto Sans CJK, Noto Sans Thai and Noto Sans Devanagari fixture fonts alone (`make corpus-fetch CORPUS=fonts`). The CJK faces are the region subsets and the `NotoSansCJK-Regular.ttc` collection the Gotenberg image installs, whose `Noto Sans CJK JP` family both converters draw an unlabelled CJK line with.

## Paper documents

`corpus build` generates the paper documents from the committed `paper-base` (about three pages: headings, justified paragraphs, quotes, a table the width of the page, a picture, its stylesheet holding `@page { size: auto; }`) and `paper-markdown` (the same text in Markdown) into the testdata (`paperDocs` in `cmd/corpus/papers.go`, `papers/<name>/`), never committed. Measured on the references: with `preferCssPageSize` false, Chromium keeps the paper of the options but takes the orientation an `@page` size names (`paper-css-ledger-landscape-paper` prints on A4 landscape, 841.92 by 595.92 points), and with it true prints an `@page` keyword size rounded to whole CSS pixels (A4 is 594.96 by 841.92 points).

| Fixture                                      | Count | What sets the page                                                                                                                                                                                                     |
| -------------------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `paper-base`, `paper-markdown`               | 2     | Committed, the corpus default paper                                                                                                                                                                                    |
| `paper-option-<paper>-<orientation>`         | 16    | `paperWidth` and `paperHeight` of A3, A4, A5 and B5 (ISO 216), Letter, Legal, Tabloid and Executive, and `landscape` for the landscape ones                                                                            |
| `paper-default-landscape`                    | 1     | `landscape` alone, on the corpus default paper, A4                                                                                                                                                                     |
| `paper-css-<keyword>-<orientation>-<mode>`   | 40    | `@page { size: <keyword> }` and `<keyword> landscape` for each keyword of CSS Paged Media Level 3 (A5, A4, A3, B5, B4, JIS-B5, JIS-B4, letter, legal, ledger), `preferCssPageSize` true (`prefer`) and false (`paper`) |
| `paper-css-lengths-<shape>-<mode>`           | 4     | `@page { size: 6in 9in }` and `25cm 15cm`, each with and without `preferCssPageSize`                                                                                                                                   |
| `paper-markdown-<paper>-<orientation>`       | 16    | `paper-markdown` on each of the eight papers, in both orientations                                                                                                                                                     |
| `paper-markdown-default-landscape`           | 1     | `paper-markdown` with `landscape` alone                                                                                                                                                                                |
| `paper-margins-<set>-<paper>-<orientation>`  | 18    | `paper-base` with `marginTop`, `marginRight`, `marginBottom` and `marginLeft` of a margin set, on A5, A4 or A3 in both orientations; A4, the corpus default, left out of the options                                   |
| `paper-markdown-margins-<set>-<orientation>` | 6     | `paper-markdown` with a margin set on the default paper, in both orientations: Markdown reaches the page through the layout HTML does, which the HTML margin documents cover on three papers                           |

The margin sets, in inches, are those of the Office corpora: `none`, all 0; `narrow`, 0.5 on every side; `uneven`, top 1, right 0.25, bottom 0.75, left 0.5. Each side is a whole quarter inch, 18 points or 24 CSS pixels, which Chromium lays out exactly. The paper a source without options prints on is the A4 the corpus posts, not the route's Letter, which no source reaches.
