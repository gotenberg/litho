# Field Notes on Paper

Markdown says what the text is. The template around it says how the page looks: the paper, the margins, the faces and the colours of this document come from `template.html`, none from the Markdown.

## Observations

- Headings take the accent colour and a rule.
- The body is set in a serif face, the headings in a sans.
- A quote carries a bar on its left:

> The page is the template's, the words are the source's.
