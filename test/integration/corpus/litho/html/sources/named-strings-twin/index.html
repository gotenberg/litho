Named strings

Each h2 sets the heading string. The page-margin boxes show it under the four keywords of string(): the first value on the page, the value at its start, the value at its end, and the first value except on the page that sets it.

Beta

Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur.

Gamma

The page starts with a heading, its top margin kept after the forced break: start shows Gamma.
