縦書きの欄を持つ頁

欄の見出し

この欄は縦に書かれ、行は右から左へ進む。

四隅の印は欄の角に置かれる。

印の位置は欄の左右上下から測る。

左上右上左下右下
注：この注は頁の左下に置かれ、欄ではなく頁から位置を測る。

本文は横に書かれ、左から右へ読む。欄は本文の右に浮かび、本文はその左を流れる。

縦書きの欄の中に置かれた絶対位置の箱は、欄の縁から測られる。上と左は欄の上と左の縁、下と右は欄の下と右の縁である。

欄の外に包含ブロックを持つ箱は、その包含ブロックの中に置かれる。ここでは頁の領域がそれである。
