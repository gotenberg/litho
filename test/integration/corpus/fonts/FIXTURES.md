# Fixture fonts

The fonts the converter cells and the litho/text builder draw with. `corpus fetch` installs each directory under `test/integration/testdata/fonts/` (gitignored), each file checked against the SHA-256 `corpus/versions.env` pins or the corpus's `files.sha256` lists; a directory already at its pins is left alone. `corpus fetch --corpus=fonts` installs every directory of the table but those of a corpus fetch, and `--corpus=fonts/<directory>` one release alone.

## Installed variable fonts

The two variable families are fixtures of installed fonts, which no directory of the Gotenberg image holds: a source names them in its `options.json` under `installedFonts`, and both litho and the reference engines convert it with them installed (see "Installed fonts" in `FEATURES.md`). Each is read from its repository at a pinned commit, with Go's default User-Agent:

- `roboto-flex`: `ofl/robotoflex/RobotoFlex[GRAD,XOPQ,XTRA,YOPQ,YTAS,YTDE,YTFI,YTLC,YTUC,opsz,slnt,wdth,wght].ttf` of `google/fonts`, installed as `RobotoFlex.ttf`, and `ofl/robotoflex/OFL.txt`. Family name `Roboto Flex`; named instances Thin to ExtraBlack, upright and italic (`slnt` -10), at `opsz` 14 and `wdth` 100.
- `source-sans-3`: `VF/SourceSans3VF-Upright.otf` of `adobe-fonts/source-sans` at the commit of its 3.052R tag, and the repository's `LICENSE.md`. Family name `SourceSans3VF`; named instances ExtraLight (the default) to Black.

Both are under the SIL Open Font License 1.1. Their licence files, as downloaded at the pins, are committed beside this file: `roboto-flex-OFL.txt` and `source-sans-3-LICENSE.txt` (the repository's `LICENSE.md`, renamed so that no formatter rewrites it). `TestFixtureFontLicences_AreTheFetchedTexts` holds each to the SHA-256 the fetch checks.
